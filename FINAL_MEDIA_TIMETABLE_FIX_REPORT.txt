GZU CAMPUS ASSISTANT — FINAL MEDIA / TIMETABLE INVESTIGATION

Changes in this consolidated package
1. Image request intent now recognizes natural singular/plural wording such as:
   - “show me gzu campuses images”
   - “show straykids pic” / “show stray kids pictures”
   Previously these phrases were not consistently routed into the image-search/gallery path.
2. When Tavily image results are empty for GZU/campus image requests, the assistant returns a small fallback gallery of known GZU-hosted image URLs. The frontend's existing media gallery renders the image cards.
3. Timetable link discovery now follows GZU official WordPress /download/ landing pages, and uses GET with a byte range instead of HEAD to validate attachment links (HEAD is often rejected by hosts).
4. When the official timetable links are actually unavailable, the assistant now explains the concrete failure and points to the official page / Examinations Office, instead of suggesting the student portal or making up an extraction.
